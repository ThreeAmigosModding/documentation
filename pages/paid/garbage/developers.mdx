# Garbage Developer Documentation

Here you will find a basic list of how you can modify our resource if you are a developer. This assumes you have *at minimum* basic knowledge of how FiveM programming works and the lua scripting language.

<Callout type="info">
    If you have any exports or events you need, please join our [Discord](https://discord.gg/YzC4Du7WY) and let us know.

    *We will provide minimal assistance when integrating other resources or implementing your own features*
</Callout>

## Hooks

Various hooks exist for you to integrate your own features, these can be found in `bridge/hooks/server.lua` and `bridge/hooks/client.lua` respectively. All of these have comments explaining how they function.

## Events & Callbacks

*Note: there are currently no accessible client events or callbacks at this time*

<Tabs items={["Server"]}>
    <Tabs.Tab>
        ### TAM_GarbageJob:fetchTruck

        This is a callback to try and spawn a truck, this will run through *all* checks before executing.

        ```lua
        --- Attempts to spawn and setup the truck.
        ---@param locationIndex number The table index from the locations.lua file.
        ---@param vehData table vehicle configuration data.
        ---@return boolean, string|integer?
        local function spawnTruck(source, locationIndex, vehData)
            return lib.callback.await("TAM_GarbageJob:fetchTruck", false, source, locationIndex, vehData)
        end
        ```

        ### TAM_GarbageJob:fetchTruckData

        Fetches a players truck data, if it exists.

        ```lua
        --- Fetches a trucks data
        ---@param source integer playerId
        ---@return privateTruckData?
        local function getTruckData(source)
            return lib.callback.await("TAM_GarbageJob:fetchTruckData", false, source)
        end
        ```

        ### TAM_GarbageJob:returnTruck

        Attempts to return a players truck, if possible.

        ```lua
        --- Attempts to return a players truck if possible.
        ---@param locationIndex integer Table index of location
        ---@param returnPos vector3 The current position, this must match one of the positions within the location config.
        TriggerServerEvent("TAM_GarbageJob:returnTruck", src, locationIndex, returnPos)
        ```

        ### TAM_GarbageJob:clockIn

        Attempts to clock the player in, if possible.

        ```lua
        --- Attempts to clock a player in, if possible.
        ---@param locationIndex integer Table index of location
        TriggerServerEvent("TAM_GarbageJob:clockIn", src, locationIndex)
        ```

        ### TAM_GarbageJob:clockOut

        Attempts to clock the player out, if possible.

        ```lua
        --- Attempts to clock the player out, if possible.
        ---@param locationIndex integer Table index of location
        TriggerServerEvent("TAM_GarbageJob:clockOut", src, locationIndex)
        ```

## Exports

<Tabs items={["Server", "Client"]}>
    <Tabs.Tab>
        ### getPlayerTruck

        Return player's truck. If ownerOnly true, return only if player is owner

        ```lua
        ---Return player's truck. If ownerOnly true, return only if player is owner (fast via map).
        ---@param src integer
        ---@param ownerOnly boolean?
        ---@return Truck?
        local truckData = exports.TAM_GarbageJob:getPlayerTruck(src, ownerOnly)
        ```

        ### handlePayout

        Handles payout distribution and cleans up truck.

        ```lua
        ---Handle payout distribution and cleanup
        ---@param src integer playerId
        ---@param truck Truck truckData from `getPlayerTruck`
        ---@param crew table? crew table.
        exports.TAM_GarbageJob:handlePayout(src, truck, crew)
        ```

        ### giveRandomItemReward

        Gives an item reward to player based on zone loot table

        ```lua
        ---Gives an item reward to player based on zone loot table
        ---@param src integer playerId
        ---@param zone string zoneId
        exports.TAM_GarbageJob:giveRandomItemReward(src, zone)
        ```

        ### getTruckConfigData

        Gets a trucks config information from its model.

        ```lua
        --- Gets a trucks config information from its model.
        ---@param model integer truckModel
        ---@return table?
        exports.TAM_GarbageJob:getTruckConfigData(model)
        ```

        ### handleDeposit

        Handles the deposit refund logic when a truck is returned.

        ```lua
        --- Handles the deposit refund logic when a truck is returned.
        ---@param src integer Player ID returning the truck
        ---@param truck Truck The truck being returned
        exports.TAM_GarbageJob:handleDeposit(src, truck)
        ```

        ### assignZoneToTruck

        Assigns a new random zone to a truck, or if there is no available zone returns nil

        ```lua
        --- Assigns a new random zone to a truck, or if there is no available zone returns nil
        ---@param truck Truck truckData
        ---@return string? newZone
        local newZone = exports.TAM_GarbageJob:assignZoneToTruck(truck)
        ```

        ### addTrashToZone

        Adds trash to the trucks current zone, if the maxCollection amount is reached it will assign a new zone.

        ```lua
        --- Adds trash to the trucks current zone, if the maxCollection amount is reached it will assign a new zone.
        ---@param truck Truck truckData
        ---@param amount integer the amount of trash to add.
        ---@return string? newZone
        local newZone = exports.TAM_GarbageJob:addTrashToZone(truck, amount)
        ```

## Statebags

### Player states:

- `garbageClockedIn` - boolean - if the player is clocked in on duty.
- `garbageCanCollectPayment` - boolean - if the player can collect payment, purely for front-end.
- `hasGarbageTruck` - boolean - if the player has a garbage truck spawned.
- `garbageTruckNetId` - string - if the player has a garbage truck spawned, its the netId.
- `inGarbageGroup` - boolean - if the player is in a group.
- `garbageGroupOwner` - boolean - player is group owner, if in one.
- `carryingBag` - integer - if the player is carrying a bag, this returns the netId
- `carryingDumpster` - integer - if the player is carrying a dumpster, this returns the netId
- `carryingBin` - integer - if the player is carrying a bin, this returns the netId

### Truck states:

- `currentTrash` - integer - the current trash that the truck has.
- `maxCapacity` - integer - the maximum capacity that the truck can hold.
- `state` - string - the state of the truck.
- `assignedZone` - string - the zone from the config that the truck has been assigned to.
- `crew` - table - the crew members of the truck.
- `owner` - integer - the owners server ID
- `isCarryingGarbage` - boolean - if the truck has a bin or dumpster attached

### Entity States:

- `garbageEmpty` - boolean - if the garbage has been emptied, purely for front-end.
